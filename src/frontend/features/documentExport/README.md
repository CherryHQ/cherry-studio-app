# Document Export Page

Owns generic format choice, preview, bounded HTML capture and user-triggered delivery. It has no
chat-specific loading or inclusion policy. The page claims its session from the app-shell handoff,
serializes superseded renders and closes the request on route exit. Markdown copying is ephemeral;
Save and Share persist a final file before any system handoff.

The capture WebView is a controlled, navigation-free surface, separate from the authored-HTML file
viewer. It releases late native files and limits physical pixels before allocation. The initial
format is one PNG; larger content offers HTML. Native acceptance is still pending.

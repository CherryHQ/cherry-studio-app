# Agent Avatar Artwork

`deepseek.png` is an AI-generated redraw of the user-supplied DeepSeek whale-girl reference.
It retains the reference's long blue hair, fin ears and maid outfit, replaces the side bow with
a Cherry hair clip, and reframes the character as a square portrait.

The [community reference metadata](https://github.com/HABAI182/ai-girls-atlas/blob/main/characters/deepseek/README.md)
credits 上善无形 for the original character and ZipZipPipe for the DeepSeek maid redesign, and
labels the selected reference as CC BY-NC-SA 4.0. This is a reference-based redraw rather than
an independently designed character; this note does not grant additional rights to that design.
